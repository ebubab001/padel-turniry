# Padla Tour — «Создай свой турнир»

Приложение для любительских турниров по ракеточным видам спорта: падел и настольный теннис.

- `padel-americano.html` — исходник приложения (он же публикуется на claude.ai).
- `src/tt-engine.js`, `src/tt-ui.js` — модуль настольного тенниса (встроен в исходник).
- `index.html` — сборка для Telegram / GitHub Pages: `./build-telegram.sh`.
- `privacy.html` — политика конфиденциальности бота.
